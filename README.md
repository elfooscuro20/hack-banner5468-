# hack-banner5468-

A minimal bash banner project for the repository name.

## Usage

Run the default banner:

```bash
./main.sh
```

Run with a custom banner label:

```bash
./main.sh "hello-from-banner"
```

You can also run the direct script:

```bash
./banner.sh "custom-banner"
```

./test.sh
